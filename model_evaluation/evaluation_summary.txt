ACADEMIC NOTES
──────────────
  1. The behavioral classifier is EMA-ratio-based (domain knowledge),
     not a trained supervised model. Classification accuracy reflects
     how well the 6-feature space separates attack archetypes.

  2. AI-UNKNOWN is a deliberate design property. When no feature
     exceeds 4x EMA, the system reports honest uncertainty rather
     than forcing a label. This is epistemically correct for an
     anomaly-based IDS.

  3. Evaluation uses synthetic ground truth because labeled live
     traffic was not available. This is the standard approach when
     captures from known attacks are impractical to obtain.

  4. The IF model separates attack from normal traffic in feature
     space. Quality depends on baseline training data captured by
     scripts/collect_baseline.py on real network traffic.

  5. The supervised RF classifier (Section D) is a second-opinion layer.
     It fires BEFORE the EMA-ratio rules when its confidence >= 70%.
     When below threshold it falls through to EMA rules, then AI-UNKNOWN.
     The BENIGN class allows the RF to suppress border-noise anomalies.
